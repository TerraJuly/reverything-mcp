# Bundled ES

This directory contains the unmodified official ES 1.1.1.40 Windows x64 executable.

- Binary archive: https://www.voidtools.com/ES-1.1.1.40.x64.zip
- Corresponding source: https://www.voidtools.com/ES-1.1.1.40.src.zip
- License: ../licenses/ES-LICENSE.txt

ES is an IPC client, not the Everything indexing engine. Users must separately
install and run Everything. The release packaging script includes this executable
and its full MIT license. Do not replace it with a different version without
rechecking command-line behavior, output format, and licensing.
